# Contract

What [the compatibility page](../docs/en/reference/compatibility.md) promises to keep within a major version, beyond
the Java API (which japicmp checks), as the code offers it today. One file per promise, one entry per line; lines
starting with `#` are comments.

| File | What | Test |
|---|---|---|
| `metrics.txt` | metric names, types, units, tag keys and values, in the Micrometer and OpenTelemetry modules | `examples` `ContractTest` |
| `snapshot-json.txt` | the endpoints' JSON (`ResilienceSnapshot.toMap()`): every path and its JSON type | `examples` `ContractTest` |
| `error-codes.txt` | every code of `docs/en/errors.md`, retired ones included | `examples` `ContractTest` |
| `config-keys.txt` | every policy attribute's key, environment variable, type and enum values | `config` `ContractTest` |
| `spring.txt` | `resilience4cata.spring.*` properties, auto-configuration class names, bean names | `spring` `ContractTest` |
| `micronaut.txt` | `resilience4cata.micronaut.*` properties | `micronaut` `ContractTest` |
| `quarkus.txt` | `quarkus.resilience4cata.*` properties, their phase and enum values | `quarkus:it` `ContractTest` |

Each test compares the code with its file and fails on any difference, telling a removed or changed line (only a new
major version may do that) from an added one (allowed in a minor version). It writes the expected file to
`<module>/build/contract/`: when the change is meant, copy it here, and the pull request shows the diff.

Code generated by an older processor is checked separately: `./gradlew :examples:check -Pr4c.generatedBy=baseline`
(CI: the `generated-code` job of `build.yml`).
